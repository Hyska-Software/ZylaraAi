---
title: Keyboard shortcuts
description: Every global, composer, palette and list shortcut in Zylara.
---

`Ctrl` on Windows and Linux, `⌘` on macOS. Shortcuts that only exist in a layout are marked.

## Global

| Shortcut | Action |
| --- | --- |
| `Ctrl/⌘ K` | Toggle the command palette |
| `Ctrl/⌘ B` | Toggle the sidebar |
| `Ctrl/⌘ N` | New conversation |
| `Ctrl/⌘ ,` | Open settings |
| `Ctrl/⌘ J` | Focus the composer (ignored while a text field is focused) |
| `Esc` | Close overlays → leave Skills or Library → stop streaming |

`Esc` is hierarchical: it closes the model picker, settings, artifacts and sources panel
first, then returns from Skills or Library to the chat, and only then stops a running answer.

## Code layout

| Shortcut | Action |
| --- | --- |
| `Ctrl/⌘ Shift+A` | New Code session |
| `Ctrl/⌘ Shift+T` | Open the terminal as a central tab |
| `Ctrl/⌘ L` | Focus the composer |

Plan mode and the permission mode have no default key binding: use the **Plan** and
permission chips in the composer, or `/plan` and `/permissions`.

## Composer

| Shortcut | Action |
| --- | --- |
| `Enter` | Send (or `Ctrl/⌘ Enter`, according to **Send with**) |
| `Shift+Enter` | Newline |
| `↑` / `↓` | Move in the `/` or `@` menu |
| `Enter` / `Tab` | Accept the highlighted item |
| `Esc` | Close the menu |
| `Ctrl/⌘ Enter` | Save and resend while editing a message |
| `Esc` | Cancel message editing |

## Command palette

| Shortcut | Action |
| --- | --- |
| `↑` / `↓` | Move |
| `Home` / `End` | First or last item |
| `PageUp` / `PageDown` | Move by page |
| `Ctrl+N` / `Ctrl+P` | Move down or up |
| `Enter` | Run the selected command |
| `Ctrl/⌘ Enter` | Run the secondary action (pin or unpin) |
| `Esc` | Clear the search, then close |

Type `>` to search only commands, `#` to search only conversations.

## Messages and lists

| Shortcut | Action |
| --- | --- |
| `Alt+↑` / `Alt+↓` | Reorder an item in a sortable list (conversations, pinned agents) |
| `Esc` | Deny a pending approval |
| `Ctrl+Alt+Shift+Q` | Release the keyboard during computer use |

## Mouse and panel actions without a shortcut

| Action | Where |
| --- | --- |
| Switch layout | Title bar pill (**Chat**, **Code**, **Agents**) |
| Hide a layout | Right-click the pill |
| Float or dock the artifacts panel | Panel header |
| Open a file in a tab | Click it in the Files tree |
| Compare with a branch | Changes filter menu |
